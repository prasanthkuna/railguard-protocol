# Railguard founder-footage edit memory

## Session 1 — production setup

- Content type: founder/engineer technical launch and education.
- Strategy approved: evidence-first, direct, calm, technically precise.
- Target masters: 30-second launch, 3-minute flagship proof, 5-minute walkthrough.
- Aspect ratios: 16:9, 9:16, 1:1.
- Grade: neutral, high-contrast, cool background, natural skin.
- Captions: sentence case, two lines maximum, Railguard blue emphasis.
- Required overlays: lifecycle, state comparison, terminal proof, honest limitations.
- Must preserve: explicit reference-implementation status and known gaps.
- Never use generated footage as technical evidence.

## Footage intake

Drop untouched camera files directly in `assets/video-launch/footage/`.

When footage exists:

1. transcribe at word level;
2. create `takes_packed.md`;
3. propose exact take and cut strategy;
4. preserve word-boundary cuts with 30–200 ms padding;
5. add 30 ms audio fades at each cut;
6. composite Railguard overlays;
7. apply subtitles last;
8. self-evaluate every cut boundary;
9. append decisions to this file.
